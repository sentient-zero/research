# publish

Variants of this article as they appear on other platforms.

The canonical version is the `README.md` one directory up. It carries the
references, the record of how the claims were checked, and the known
limitations. These files do not.

Each variant is the same article body with whatever the destination requires
added or removed: a source link, a bio line, formatting that platform can
render. Where a variant differs from the canonical text in any way that affects
meaning, the difference is noted at the top of that file.
