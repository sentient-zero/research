# research

Security research by Joe Doran, currently working in offensive security and AI red
teaming.

Each piece lives in its own directory. The directory `README.md` is the canonical
version and carries the full apparatus: references with a status on every source,
a record of how the claims were checked, and any known limitations. Variants
published elsewhere sit under `publish/` in the same directory, and supporting
material sits under `assets/`.

Claims are traced to primary sources. Where a source could not be read directly,
the reference table says so. Where an argument did not survive verification, it
is recorded alongside the ones that did.
